# First Encounter 001

This is the visual cousin of First-Listen Radio.

It exists for returned artifacts that are not audio, beginning with a Haunted Toaster witness sigil.

## Law

The station may remember. The ordinary listener may not.

```text
artifact
  ↓
strict bounded packet
  ↓
isolated fresh listener
  ↓
sealed first response
  ↓
only then may history/dialogue re-enter
```

The request schema accepts only:

- schema;
- artifact media type;
- artifact SHA-256;
- exact artifact text.

Extra history/context fields are refused.

## No simulated listener

If a real Gemini key is unavailable, the instrument returns:

```text
status = packet-only
response = null
```

It does not substitute canned prose, random prose, or a role-played fake first response.

## TAO modes

A real response separates:

- OBSERVED;
- DERIVED;
- METAPHOR;
- INTERPRETATION.

This separation is descriptive evidence, not authority.

## Relationship to First-Listen Radio

This does not replace the music-first radio canon. It proves the isolation primitive on a small returned visual artifact so the same law can later carry audio windows.
